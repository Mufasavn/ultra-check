# Private archive policy

Keep this repository Private. No Pages, deployment workflow, public release, collaborator invitation or external hosting is part of this upload.

The source is the released 2.9 source snapshot, with archive documentation and ignore rules added. No user API tokens, proxy passwords, encrypted vaults, bookmarks, query history, local databases or error logs are included. Test fixtures contain synthetic credentials only.

Application screenshots containing an actual local Windows profile path are omitted. The verified Windows EXE is included at the repository root so Download ZIP contains the runnable application. Original Windows/source ZIP bundles remain local; build instructions and the executable checksum are retained here. Third-party notices remain in NOTICES.txt; no new open-source license for the application has been granted.
